# Help

## Ejecutar las pruebas

Elige tu sistema operativo:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Abre el Command Prompt.
2. Descarga el primer ejercicio:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Cambia al directorio del ejercicio:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Ejecuta las pruebas:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(No te preocupes si las pruebas fallan al principio, así es como empiezas cada ejercicio.)_

5. Resuelve el ejercicio. Busca la guía `instructions.append.md` y síguela ([ver en GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

¡Mucha suerte! ¡Que te diviertas!

## Enviar tu solución

Puedes enviar tu solución con el comando `exercism submit src/main/java/Badge.java`.
Este comando subirá tu solución al sitio web de Exercism e imprimirá la URL de la página de la solución.

Es posible enviar una solución incompleta, lo que te permite:

- Ver cómo otras personas completaron el ejercicio
- Solicitar ayuda de un mentor

## ¿Necesitas ayuda?

Si quieres ayuda para resolver el ejercicio, consulta las siguientes páginas:

- La [documentación del track Java](https://exercism.org/docs/tracks/java)
- La [categoría de programación del track Java en el foro](https://forum.exercism.org/c/programming/java)
- La [categoría de programación de Exercism en el foro](https://forum.exercism.org/c/programming/5)
- Las [preguntas frecuentes](https://exercism.org/docs/using/faqs)

Si esos recursos no son suficientes, puedes enviar tu solución (incompleta) para solicitar mentoría.

Si necesitas ayuda, puedes visitar estos recursos:

- [Stack Overflow](https://stackoverflow.com/questions/tagged/java),
- [El subreddit de Java](https://www.reddit.com/r/java),
- [Documentación oficial de Java](https://docs.oracle.com/en/java/javase/11/docs/api/index.html).
